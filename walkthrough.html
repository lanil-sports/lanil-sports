LANILSPORTS.COM Backend Architecture

Louisiana High School Athlete Directory & NIL Platform (Operating Model & Defense Moat)

1. The $0 High-Performance Tech Stack

Frontend & Edge CDN

Cloudflare Pages ($0): Ultra-fast global static CDN, free SSL certificates, and custom domain mapping for lanilsports.com.

Database & Authentication

Supabase ($0): Cloud PostgreSQL database holding 64 Louisiana parishes, all LHSAA schools, and athlete profiles with Row-Level Security.

Automated Scraper / Cron

GitHub Actions ($0): Scheduled runners (2,000 free minutes/mo) waking up every Tuesday at 6 AM CST to parse Louisiana sports RSS feeds.

Monetization Gateway

Stripe ($0 Upfront): Zero monthly fee. Charges 2.9% + 30¢ only when parents or recruiters purchase subscriptions.

2. Step-by-Step Data Flow

  1. Weekly News Scraping: Every Tuesday morning, the GitHub Actions script queries Louisiana RSS feeds (The Advocate, NOLA.com, The News-Star) for keyword mentions of touchdowns, points, and all-district awards.
  2. Entity Matching & Deduplication: Checks composite key Full_Name + High_School. Existing athletes receive updated stats; unlisted athletes receive a newly generated unique Player ID (e.g. LA-2027-0005).
  3. Athlete Claiming: When an athlete or guardian claims their profile, parent consent is recorded under Louisiana Act 810 (La. R.S. 17:3705) and their updates save straight to Supabase.
  4. Freemium Paywall: Public directory shows headshots, schools, and season stats. Full recruiting dossiers (verified offers, local NIL valuations, engagement analytics) are unlocked for paid subscribers.

3. How LANIL Defends Against Copycats & Scrapers

1. Database Row-Level Security (RLS)

The public anon key cannot access private minor contact details, internal notes, or raw guardian authorizations. Bulk data dump scripts are blocked by Supabase policy limits.

2. Cloudflare Bot Fight Mode

Cloudflare analyzes incoming traffic at the edge and blocks headless scrapers (Puppeteer, Scrapy, Python curl bots) before they can even touch your website.

3. Anti-Framing Security

HTTP response headers include X-Frame-Options: DENY so competitors cannot embed your portal inside their own websites.

4. The Un-Copyable Community Network

A competitor can scrape static text once, but they cannot steal the parents voting every week, the athletes updating their own profiles, or the local parish sponsor relationships.
